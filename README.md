# Black & White Portfolio

A sleek, modern, and minimalist professional portfolio built with **Vue 3**. This project features a striking black-and-white aesthetic, smooth GSAP animations, and a mobile-first responsive design.

## ✨ Features

- **Vue 3 (Composition API)**: Built using the latest Vue standards for performance and developer experience.
- **GSAP Animations**: Fluid scroll-triggered animations and transitions.
- **PWA Support**: Installable as a web app with offline capabilities.
- **Mobile Responsive**: Fully optimized for all screen sizes (mobile, tablet, desktop).
- **Modern UI/UX**: Clean black-and-white theme with high-contrast typography.

## 📁 Project Structure

```bash
src/
├── assets/         # Images, fonts, and static assets
├── components/     # Reusable Vue components (Bio, Work, Featured sections)
├── composables/    # Shared logic (e.g., screen size detection)
├── router/         # Vue Router configuration
├── styles/         # Global SCSS themes and variables
└── views/          # Top-level page views (Home, About)
```

## 🛠️ Project Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run serve
```

### 3. Build for Production
```bash
npm run build
```

### 4. Lint and Fix Files
```bash
npm run lint
```

## 🚀 Key Components

- **BioSection**: Introduction and CTA with dynamic image loading.
- **FeaturedSection**: Showcasing major professional projects.
- **WorkSection**: Detailed look at past experience and contributions.
- **PersonalProjects**: Secondary projects and experiments.
